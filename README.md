# ソルフェ道場 — ギター×ソルフェージュ(音感×リズム)トレーナー

「耳トレ」(旧版は `classic.html`)と「Strum Master」(~/strum-master)を統合した、移動ドによる相対音感・ギターのリズム感・指板・譜読みを鍛える個人用トレーナー。
アプリ本体は `index.html` 1ファイル(ビルド不要)。音は実楽器サンプル(`samples/`)を Web Audio で再生し、読めない環境では合成音にフォールバック。
進捗は localStorage(`solfaDojo_v1`)。PWA 対応(ホーム画面に追加・オフライン動作)。

## 起動

- 公開版(https・スマホ可・マイク判定可):GitHub Pages
- ローカル:`python3 -m http.server 8124 --directory ~/ear-trainer` → http://localhost:8124
  (マイク判定は https か localhost のときだけ有効。`file://` では自己採点モード)

## 構成

```
index.html              アプリ本体(HTML/CSS/JS)
sw.js                   Service Worker(本体はネット優先、音源・アイコンはキャッシュ優先)
manifest.webmanifest    PWA マニフェスト
icons/                  アイコン(192/512/apple-touch)
samples/{nylon,steel,piano}/<MIDI番号>.mp3   MIDI 36〜88 の実音サンプル
classic.html            旧版「耳トレ」
```

## 音源のクレジット

[gleitz/midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts) から取得。
- ナイロン弦・スチール弦ギター:FluidR3_GM — CC BY 3.0
- ピアノ:Musyng Kite — CC BY-SA 3.0

採用前に全サンプルのピッチを自己相関法で計測し、ナイロン弦は中央値1セント・90%タイル4セント以内のずれであることを確認済み。

## 音感(9コース・74レッスン)

| コース | 内容 |
|---|---|
| 🎯 度数聴音 | ドレミファソラシド(設定でカデンツも可)でキーを確立 → 音の度数(移動ド)を当てる。ド・ミ・ソ → 長音階 → 転調 → 短調 → 12音 → 3音連続 |
| ✍️ 旋律聴音 | 3〜8音のメロディを移動ドで書き取り(最初の音は表示) |
| 🎸 指板マスター | 弦ごとの音名 → 音名から探す → E型/A型ボックスでの度数 → 聴いて押す |
| 📏 インターバル | 上行・下行・和声的、全12種。覚え方の曲つき |
| 🎹 和音と進行 | コード8種、I–IV–V〜♭VII の進行(選択式・書き取り式) |
| 📜 譜読み | ト音記号(ギターは1オクターブ下で鳴る)→ 音名/指板 |
| 🎤 視唱・弾き返し | マイクのピッチ検出(自己相関)で歌う/ギターで弾き返す。オクターブ不問 |
| 🐣 こども音楽教室 | 幼児の音楽教室のような段階づけ:声を出す → 声の高さを測る(以後のお手本をその高さで鳴らす)→ 高い・低い → サイレン → 同じ音 → ド・ソ → ドレミ → ドミソ → かえるのうた。許容±40〜50¢、合わなければお手本を聴き直して再挑戦 |
| 🎙️ 発声・音程 | 歌った音程をセント単位で採点(ロングトーン/ピッチマッチ/音階上下/跳躍/視唱/短調/3度ハモり/半音)。リアルタイム音程グラフ、上ずり・ぶら下がりの傾向表示 |

- 7/10 で★1(次を解放)、9 で★2、10 で★3。

## リズム(3コース・25レッスン)

| コース | 内容 |
|---|---|
| 🥁 拍感とグルーヴ | 4分/8分/裏拍/2・4拍クリック/3連/16分/クリック消失/分割チェンジ |
| 🎸 ストローク | Strum Master の10ステージ。ダウン/アップ判定モード(画面左右・F/J)あり |
| 📖 リズム読み・聴音 | リズム聴音(聴いてマス目譜面を選ぶ)と初見リズム(NEXT 先読み) |

- 各レッスンはテンポ3段階。ランクB以上で★、C以上で次のテンポ解放。判定は やさしい/標準/シビア。
- タップ遅延キャリブレーション(クリック16回の中央値)、結果画面にタイミング散布図+ヒストグラム+苦手位置。

## ゲーム(音感×リズムを同時に)

- 🎹 **ソルフェ・ヒーロー**:落ちてくる音をドレミのレーンで弾いてメロディを完成(パブリックドメインの8曲)。👂耳コピモード(レーン非表示)、ゆっくりモード、今日の1曲 XP×2、ランクBで次の曲解放。
- 🔁 **エコー・セッション**:1小節聴く→次の1小節で同じ音・同じリズムで弾き返す。3ライフ、成功ごとに加速・音域拡大(7段階)。
- ⚡ **リズム・サバイバル**:止まらないストローク、2小節ごとに加速。MISS 3回で終了、16コンボで回復。
- 🚀 **音階ラッシュ**:鳴った音のドレミを制限時間内に当てる。時間は徐々に短縮、速いほど高得点、10連続で×2・20連続で×3(FEVER)。8問ごとにレベルアップ(ドミソ→長音階→音域拡大→転調→12音)、ミス3回で終了。
- ⏱️ 60秒チャレンジ(音感4種)
- 間違えると正解の音が「ドへ解決する流れ」を再生(機能和声的聴音)。
- 図鑑:スケール図鑑(10種・12キー・移動ド/度数/音名表示)と読み物11本(再生ボタン付き)。

## 開発メモ

- リズムエンジンは `rgStart(cfg)`。小節を `cfg.bar(i)` で遅延生成し、Web Audio クロックに先行予約(2.6秒先まで)。
  判定は `rgTap` → `rgJudge`、見逃しは `rgTick`(25ms)で確定。エンドレスモードもこの仕組みで実装。
- 問題ジェネレーターは `GEN.<name>(params, ctx)` で、`{kind:'choice'|'seq'|'fret'|'mic', prompt, play, options, correct, ...}` を返す。
  レッスンは `TRACKS[].lessons[]` に `{gen, p}` を足すだけで増やせる。
- 声のレッスンは `startVoice(id)`(`voice.mode` が 'task' なら課題型、それ以外は音程型)。画面は目標の段を中心に±7半音の「はしご」と声の玉で表示し、ずれが大きくても矢印で示す。マイクのコールバックで目標との差(オクターブ折り返し)を集め、`VHOLD` 秒ぶん溜まったら中央値と標準偏差から採点(±10¢≒94点、±25¢≒76点、±50¢≒46点)。
- 音階ラッシュは `startRush()`、レベル定義は `RUSH_LV`。
- 統計キー:`deg:`/`degm:`(度数)、`int:<半音><u|d|h>`、`fn:<弦>-<フレット>`、`chd:`、`sn:`/`sf:`(譜読み)など。
- 設定画面からバックアップ(JSON)の書き出し/読み込みが可能。
